# Security

Please report a vulnerability privately, through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**, or go straight to <https://github.com/jackmossman/agentamph/security/advisories/new>.

Please don't open a public issue for a vulnerability. You'll get a reply in the advisory, and a fix will be released with a new version and a `CHANGELOG.md` entry.

Only the latest release is supported.
